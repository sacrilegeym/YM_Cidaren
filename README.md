## 相对上游的改动

1. **打包为单文件 exe**：PyInstaller onefile，无需安装 Python 与依赖，双击即用。
2. **移除外部 mitmdump 依赖**：token 抓取改为进程内 `mitmproxy DumpMaster`（后台线程 + 独立事件循环），
   单文件也能直接抓包。
3. **路径分离**：资源（模型/图标/默认配置）打进 exe，数据（`config/`、`log/`）写到 exe 旁边，
   首次运行自动生成。
4. **启动询问是否自动捕获 token**：选「是」自动抓取，选「否」直接进入主界面。
5. **界面重构**：
   - 去掉 CMD 黑框，日志与异常统一进「输出信息」面板（带时间戳、错误分级）；
   - 新增「题目详情」面板：题号/题型、题干、译文、全部选项、已提交项；
   - 新增任务计时器（实时已用时，结束写总结）；
   - 新增「用时范围」调速：两位小数、上下限区间随机、加速/减速、风险分级提示。
6. **答题准确率相关改动**（核心）：
   - 词典例句反查：题干句子与平台例句库完全一致时，直接用该例句所属义项（确定性判据，
     实测覆盖约 44% 的题）；
   - 义项消歧：题干中文译文分词打分 + 覆盖度 + spaCy 词性 + 匹配层级；
   - 题目记忆库：答对记正解、答错记错项（负记忆），同题再遇到直接命中/排除；
   - 分层词义匹配（精确 → 字符集 → 包含 → 相似度），修掉"错误选项抢先命中"的老 bug。
7. **答案库查找**：精确 → 归一化 → 去词性 三级回退（兼容引号/全半角/词性前缀差异）。
8. **代理残留自愈**：启动时检测并清理上次异常退出遗留的系统代理。
9. 窗口标题改为 `YM词达人`。

## 使用说明

1. 下载 Release 里的 `YM词达人.exe`，放到任意**可写目录**（不要放 C:\Program Files）。
2. 双击运行，弹窗询问是否自动捕获 token：
   - 选「是」→ 自动配置系统代理并抓取微信里的 UserToken（期间不要在其它设备登录词达人）；
   - 选「否」→ 手动粘贴 token，或用「帮助 → 获取 token → 内置」。
3. 首次运行会在 exe 旁生成 `config/`（配置与答案库）和 `log/`（日志）。
4. 底部「用时范围」建议：班级测试 5~8 秒（10 秒限时留余量）；自学任务 1~2 秒。
   **低于 0.5 秒属极高风险区**，容易被平台风控判定为脚本。

## 本仓库不含任何用户数据

- 不含 token、日志、答题记录、个人身份信息。
- `config/answer_lib.json` 为上游原始题库（221 条），不是任何人的刷题积累。
